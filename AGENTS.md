# Agent Instructions

This repository defines the project and coding standards. All AI coding agents and human contributors follow the same rules.

## Required

1. Read [`docs/standards/README.md`](docs/standards/README.md) before making changes. It indexes every standard.
2. Follow every standard marked `Active` that applies to the work you are doing.
3. If a request conflicts with a standard, say so and ask before deviating.
4. When asked to add or change a rule, edit `docs/standards/` and update its index. Do not put rules in this file or in other agent entry files.

## Notes

- This file and the tool-specific entry files (`CLAUDE.md`, `GEMINI.md`, `.github/copilot-instructions.md`, `.cursor/rules/`, `.windsurfrules`) are pointers only.
- Rules live in `docs/standards/` and nowhere else.
